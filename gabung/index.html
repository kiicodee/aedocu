Gabung PDF · tanpa upload

Satukan PDF jadi satu file.

Pilih beberapa PDF, tarik untuk mengatur urutannya, lalu gabungkan. Isi dan kualitas setiap halaman tetap seperti aslinya, dan file kamu tidak pernah meninggalkan perangkat ini.

Tarik beberapa PDF ke sini atau klik untuk memilih · bisa pilih banyak sekaligus

1Atur urutan

Tarik kartu (atau pakai tombol ← →) untuk mengatur urutan. File paling kiri jadi halaman paling depan.

Cara pakai

Tiga langkah, tanpa daftar akun

  1. Pilih PDFPilih atau tarik dua file PDF atau lebih. Bisa ditambah lagi kapan saja.
  2. Atur urutanTarik kartunya ke posisi yang kamu mau, atau urutkan berdasarkan nama.
  3. Gabungkan & simpanHasilnya satu PDF bernama nama-file-gabung.pdf.
FAQ

Yang sering ditanyakan

Apakah ada batas jumlah atau ukuran file?

Tidak ada. Batasnya hanya memori perangkatmu. Puluhan file dengan ratusan halaman biasanya lancar di laptop.

Apakah kualitasnya turun?

Tidak. Halaman disalin apa adanya, tidak dikompres ulang. Kalau hasilnya terlalu besar, kecilkan dengan alat Kompres PDF.

Apakah bookmark dan kolom isian ikut?

Isi halaman dan link di dalam halaman ikut. Bookmark (daftar isi di samping) dan kolom isian dari file asli belum ikut digabung.

Bisa untuk PDF yang dikunci kata sandi?

Belum. Buka dulu kuncinya dengan aplikasi yang membuatnya. Mampat akan memberi tahu file mana yang terkunci.
